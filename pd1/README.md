## Palaišana

Terminālī no krātuves saknes:

python pd1/kods/sveiciens.py

Ja terminālis jau atrodas mapē `pd1/kods`, pietiek ar `python sveiciens.py`. Python ceļu skaita no mapes, kurā stāv terminālis, nevis no faila atrašanās vietas.

## Struktūra

- `kods/sveiciens.py` - programma, kas izdrukā autora vārdu un kursa nosaukumu
- `README.md` - šis apraksts
- `piezimes.txt` - personīgi pieraksti; `.gitignore` tos bloķē, tāpēc GitHub tie nenonāk

## Ergonomika

- Monitors acu līmenī, rokas stiepiena attālumā - kakls nav jāliec uz leju.
- Noteikums 20-20-20: ik pēc 20 minūtēm 20 sekundes skatos uz kaut ko 6 metru attālumā, lai atpūtinātu acis.
- Taisna mugura, kājas uz grīdas, elkoņi aptuveni taisnā leņķī - mazāka slodze mugurai un plaukstu locītavām.
- Pārtraukums reizi stundā: piecelties un pakustēties.
